Exhibit 1

Crossover explorer

How much history does a user need before personalization beats popularity? The measured answer here is that it doesn't: ALS and item-kNN sit below the popularity baseline in every one of the five frozen history-depth segments, and while the deficit is smaller at 20+ interactions than in the shallow segments, it is still open at the deepest segment this 5-core TEST set contains. The only model that clears popularity is the blend that contains it. That absence is the finding — the exhibit below is what it looks like: one line per model, 95% bootstrap CI bands, and the n* slider that shows what a routing threshold would have bought at every recorded grid position (the fitted answer is n*=∞ — the optimal routing is no routing). Phase 8 added the two recency-matched arms (item-kNN-t12m and ALS-decay hl365, one preregistered TEST run each) and an exploratory extension of the depth axis to 20-49 / 50-99 / 100+; the depth-level null survived both. The five-cell pocket they surfaced lives in the regime map below (Exhibit 1b) as a mechanism footnote — under ~80 uncorrected tests it is not a crossover finding. Exhibit 1b

Regime map — where each model stops working

Phase 8 (T8-1) measured the churn the Phase 4 verdict had only inferred: 41.11% of TEST ground-truth purchases land on items with at most 4 TRAIN interactions — items a TRAIN-frozen model structurally cannot rank. That churn is the measured mechanism behind the headline null. The grid below stratifies the paired delta against pop-t12m by user history depth × the target item's TRAIN support or recency. Recency-matched item-kNN-t12m (T8-2) beats pop-t12m in five cells with per-cell 95% CIs excluding zero on both metrics — a mechanism footnote, not a crossover: the cells come from ~40 cells × 2 arms ≈ 80 uncorrected tests, of which ~4 would be expected significant at α=0.05 by chance, and dual-metric agreement plus clustering is partial evidence, not a correction. ALS-decay is null everywhere and static ALS (T8-1 baseline) never wins a cell. Every number is clickable — it opens the results-log record it came from.

Exhibit 1c

Regime contrast — Amazon Electronics vs ML-32M

Phase 9 (T9-3) re-ran the churn gate and the same preregistered crossover test on a second dataset. ML-32M's catalog churn is 6.40% (band <0.10, "churn diagnosis wrong" for that dataset's own gate) against Amazon Electronics' measured 41.11% — the two datasets sit in different regimes on the mechanism this case study identified. In that low-churn regime, item-kNN-t12m (M*) beats pop-t12m (P*) NDCG@10 with the 95% CI excluding zero, BH-significant, in three coherent history-depth buckets (20-49, 50-99, 100+): a preregistered D1 crossover at n*=20. It is a regime contrast, not a causal proof, and it comes with real qualifications below — the Recall@20 guard does not agree, and the same run shows a large, significant cold-user loss.
